## Overview

`DrawableRecipientChip` is an interface that defines a drawable object containing information relevant to a particular recipient. It extends `BaseRecipientChip` and adds drawing capabilities for visual representation of recipient chips.

**Package**: `com.android.ex.chips.recipientchip`

**Extends**: `BaseRecipientChip`

## Methods

### getBounds()

```java
Rect getBounds()
```

Returns the bounds of the chip. May be 0,0 if the chip is not visibly rendered.

<ResponseField name="return" type="Rect">
  The bounding rectangle of the chip
</ResponseField>

### draw()

```java
void draw(Canvas canvas)
```

Draws the chip on the provided canvas.

<ParamField path="canvas" type="Canvas" required>
  The canvas on which to draw the chip
</ParamField>

## Implementations

The Android Chips library provides two main implementations:

### VisibleRecipientChip

A visible chip that renders with a background, text, and optional avatar icon.

- Used when chips are displayed normally in the RecipientEditTextView
- Renders with custom drawables for background and selected state
- Shows contact photos when available
- Can display delete icon when selected

### InvisibleRecipientChip

A chip that doesn't render visually but maintains recipient data.

- Used internally when chips are hidden (e.g., when "more" chip is shown)
- Maintains all recipient information without visual representation
- Has zero bounds (0,0,0,0)

## Usage with RecipientEditTextView

### Getting Chips from the View

```java
RecipientEditTextView recipientEdit = findViewById(R.id.recipient_edit_text);

// Get all chips
DrawableRecipientChip[] chips = recipientEdit.getRecipients();

// Get sorted chips
DrawableRecipientChip[] sortedChips = recipientEdit.getSortedRecipients();

// Process chips
for (DrawableRecipientChip chip : chips) {
    String display = chip.getDisplay().toString();
    String value = chip.getValue().toString();
    boolean selected = chip.isSelected();
    
    Log.d("Chip", display + " <" + value + "> selected: " + selected);
}
```

### Working with Chip Data

```java
DrawableRecipientChip chip = getChip();

// Get recipient information
RecipientEntry entry = chip.getEntry();
String displayName = entry.getDisplayName();
String destination = entry.getDestination();

// Check chip state
if (chip.isSelected()) {
    Log.d("Chip", "Chip is selected");
}

// Get contact information
long contactId = chip.getContactId();
if (contactId != RecipientEntry.INVALID_CONTACT && 
    contactId != RecipientEntry.GENERATED_CONTACT) {
    // This is a real contact from the database
    String lookupKey = chip.getLookupKey();
    long dataId = chip.getDataId();
}

// Get visual bounds
Rect bounds = chip.getBounds();
int width = bounds.width();
int height = bounds.height();
```

### Custom Drawing

```java
// Example of custom chip rendering (typically done internally)
public void drawChipOnCanvas(DrawableRecipientChip chip, Canvas canvas) {
    // The chip handles its own drawing
    chip.draw(canvas);
    
    // Or get bounds for custom rendering
    Rect bounds = chip.getBounds();
    // ... custom drawing logic
}
```

### Managing Chip Selection

```java
DrawableRecipientChip chip = getChip();

// Select a chip
chip.setSelected(true);

// Deselect a chip
chip.setSelected(false);

// Toggle selection
chip.setSelected(!chip.isSelected());

// Check if any chips are selected
DrawableRecipientChip[] chips = recipientEdit.getRecipients();
boolean hasSelection = false;
for (DrawableRecipientChip c : chips) {
    if (c.isSelected()) {
        hasSelection = true;
        break;
    }
}
```

### Working with Original Text

```java
DrawableRecipientChip chip = getChip();

// Get original text (before contact lookup)
CharSequence originalText = chip.getOriginalText();

// Set original text (typically done by RecipientEditTextView)
chip.setOriginalText("john@example.com, ");
```

## Common Patterns

### Extracting All Email Addresses

```java
public List<String> getAllEmailAddresses(RecipientEditTextView view) {
    List<String> emails = new ArrayList<>();
    DrawableRecipientChip[] chips = view.getSortedRecipients();
    
    for (DrawableRecipientChip chip : chips) {
        String email = chip.getEntry().getDestination();
        if (email != null && !email.isEmpty()) {
            emails.add(email);
        }
    }
    
    return emails;
}
```

### Finding Chips by Contact ID

```java
public DrawableRecipientChip findChipByContactId(
    RecipientEditTextView view,
    long contactId
) {
    DrawableRecipientChip[] chips = view.getRecipients();
    
    for (DrawableRecipientChip chip : chips) {
        if (chip.getContactId() == contactId) {
            return chip;
        }
    }
    
    return null;
}
```

### Validating All Chips

```java
public boolean areAllChipsValid(RecipientEditTextView view) {
    DrawableRecipientChip[] chips = view.getRecipients();
    
    for (DrawableRecipientChip chip : chips) {
        if (!chip.getEntry().isValid()) {
            return false;
        }
    }
    
    return true;
}
```
