## Overview

`RecipientEntry` represents one entry inside the recipient auto-complete list. It contains all the information about a recipient, including display name, destination (email or phone), contact ID, and photo data.

**Package**: `com.android.ex.chips`

## Constants

### Contact Types

<ResponseField name="INVALID_CONTACT" type="int">
  Indicates an invalid contact ID (value: -1)
</ResponseField>

<ResponseField name="GENERATED_CONTACT" type="int">
  Indicates a contact generated from external source, not a real contact (value: -2)
</ResponseField>

<ResponseField name="INVALID_DESTINATION_TYPE" type="int">
  Invalid destination type that shouldn't be used for display (value: -1)
</ResponseField>

### Entry Types

<ResponseField name="ENTRY_TYPE_PERSON" type="int">
  Entry type for person entries (value: 0)
</ResponseField>

<ResponseField name="ENTRY_TYPE_SIZE" type="int">
  Total number of entry types (value: 1)
</ResponseField>

## Usage Examples

### Creating a Simple Email Entry

```java
// Create entry from just an email address
RecipientEntry entry = RecipientEntry.constructFakeEntry(
    "user@example.com",
    true
);
```

### Creating an Entry with Name and Email

```java
// Create entry with display name and email
RecipientEntry entry = RecipientEntry.constructGeneratedEntry(
    "John Doe",
    "john@example.com",
    true
);
```

### Creating an Entry with Photo

```java
// Create entry with name, email, and photo
Uri photoUri = Uri.parse("content://contacts/photo/123");
RecipientEntry entry = RecipientEntry.constructGeneratedEntry(
    "Jane Smith",
    "jane@example.com",
    photoUri,
    true
);
```

### Creating from Contact Data

```java
// Create entry from contact database
RecipientEntry entry = RecipientEntry.constructTopLevelEntry(
    "John Doe",                          // display name
    DisplayNameSources.STRUCTURED_NAME,  // name source
    "john@example.com",                  // destination
    Email.TYPE_WORK,                     // type
    null,                                // label
    123L,                                // contact ID
    null,                                // directory ID
    456L,                                // data ID
    "content://contacts/photo/123",      // photo URI
    true,                                // is valid
    "lookup_key_123"                     // lookup key
);
```

### Working with Entry Data

```java
RecipientEntry entry = getRecipientEntry();

// Get basic information
String name = entry.getDisplayName();
String email = entry.getDestination();
boolean valid = entry.isValid();

// Check entry type
if (RecipientEntry.isCreatedRecipient(entry.getContactId())) {
    // This is a user-entered recipient, not from contacts
    Log.d("Entry", "User-generated entry");
}

// Get photo if available
Uri photoUri = entry.getPhotoThumbnailUri();
if (photoUri != null) {
    byte[] photoBytes = entry.getPhotoBytes();
    if (photoBytes != null) {
        Bitmap photo = BitmapFactory.decodeByteArray(
            photoBytes, 0, photoBytes.length
        );
    }
}

// Get contact details
long contactId = entry.getContactId();
long dataId = entry.getDataId();
String lookupKey = entry.getLookupKey();
```
