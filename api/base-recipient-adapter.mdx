## Overview

`BaseRecipientAdapter` is an adapter for showing a recipient list in auto-complete suggestions. It queries the contacts provider and provides filtered results for email addresses or phone numbers.

**Package**: `com.android.ex.chips`

**Extends**: `BaseAdapter`

**Implements**: `Filterable`, `AccountSpecifier`

## Usage Example

```java
// Create adapter for email queries
BaseRecipientAdapter adapter = new BaseRecipientAdapter(context);

// Or create adapter for phone queries
BaseRecipientAdapter phoneAdapter = new BaseRecipientAdapter(
    BaseRecipientAdapter.QUERY_TYPE_PHONE,
    context,
    20  // max results
);

// Set account to prioritize
Account account = new Account("user@example.com", "com.google");
adapter.setAccount(account);

// For phone adapter, show only mobile numbers
phoneAdapter.setShowMobileOnly(true);

// Register observer for updates
adapter.registerUpdateObserver(new BaseRecipientAdapter.EntriesUpdatedObserver() {
    @Override
    public void onChanged(List<RecipientEntry> entries) {
        // Handle entry updates
        Log.d("Adapter", "Received " + entries.size() + " entries");
    }
});

// Set up chip layouter
DropdownChipLayouter layouter = new DropdownChipLayouter(
    LayoutInflater.from(context),
    context
);
adapter.setDropdownChipLayouter(layouter);

// Use with RecipientEditTextView
RecipientEditTextView recipientEdit = findViewById(R.id.recipient_edit_text);
recipientEdit.setAdapter(adapter);
```
