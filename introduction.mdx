# Introduction to Android Chips

Android Chips is a simple, lightweight library that brings Material Design contact chips to your Android applications. Based on Google's internal chips library, it provides a polished autocomplete text view that displays selected contacts as interactive, removable chips.

## What are chips?

Chips are compact elements that represent an input, attribute, or action. This library implements contact chips following the [Material Design specification](http://www.google.com/design/spec/components/chips-tokens.html#chips-tokens-contact-chips), allowing users to select and manage multiple recipients in a visually appealing way.

## Quick preview

Here's how simple it is to add email chips to your app:

```java
final RecipientEditTextView emailRetv = 
        (RecipientEditTextView) findViewById(R.id.email_retv);
emailRetv.setTokenizer(new Rfc822Tokenizer());
emailRetv.setAdapter(new BaseRecipientAdapter(this));
```

Once configured, users can type to search contacts, select recipients, and see them displayed as Material Design chips. Each chip shows the contact's name and can be tapped to view alternatives or removed with a simple gesture.

## What you'll build

With Android Chips, you can create messaging interfaces, email clients, or any app that needs multi-recipient selection. The library handles:

- Contact searching and filtering
- Chip rendering with contact photos
- Selection and removal interactions
- Alternative contact methods (multiple emails/numbers per contact)
- Mobile-only filtering for phone numbers

## Requirements

- Android API 11 (Honeycomb) or higher
- Android Support Library v4
- READ_CONTACTS permission for autocomplete functionality
