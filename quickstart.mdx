Get your first chips autocomplete view working in just a few steps. This guide will show you how to implement both email and phone number autocomplete using the Android Chips library.

<Note>
  Before starting, make sure you've completed the [installation](/installation) steps and configured the READ_CONTACTS permission.
</Note>

## Email recipient selection

Create an autocomplete field for email addresses with these simple steps:

<Steps>
  <Step title="Add the view to your layout">
    Add `RecipientEditTextView` to your XML layout:

    ```xml
    <com.android.ex.chips.RecipientEditTextView
        android:id="@+id/email_retv"
        android:layout_width="match_parent"
        android:layout_height="wrap_content" />
    ```
  </Step>

  <Step title="Configure the view in your Activity">
    Set up the email autocomplete with `Rfc822Tokenizer`:

    ```java
    final RecipientEditTextView emailRetv =
            (RecipientEditTextView) findViewById(R.id.email_retv);
    emailRetv.setTokenizer(new Rfc822Tokenizer());
    emailRetv.setAdapter(new BaseRecipientAdapter(this));
    ```
  </Step>
</Steps>

That's it! Your email autocomplete is ready to use.

<Info>
  The `Rfc822Tokenizer` is designed for email addresses and follows the RFC 822 standard, allowing formats like "John Doe &lt;john@example.com&gt;".
</Info>

## Phone number selection

For phone number autocomplete, use `QUERY_TYPE_PHONE` and `CommaTokenizer`:

<Steps>
  <Step title="Add the view to your layout">
    Add `RecipientEditTextView` to your XML layout:

    ```xml
    <com.android.ex.chips.RecipientEditTextView
        android:id="@+id/phone_retv"
        android:layout_width="match_parent"
        android:layout_height="wrap_content" />
    ```
  </Step>

  <Step title="Configure the view with phone adapter">
    Set up the phone autocomplete:

    ```java
    final RecipientEditTextView phoneRetv =
            (RecipientEditTextView) findViewById(R.id.phone_retv);
    phoneRetv.setTokenizer(new MultiAutoCompleteTextView.CommaTokenizer());
    BaseRecipientAdapter baseRecipientAdapter = new BaseRecipientAdapter(
        BaseRecipientAdapter.QUERY_TYPE_PHONE, 
        this
    );
    
    // Queries for all phone numbers. Includes phone numbers marked as "mobile" and "others".
    // If set as true, baseRecipientAdapter will query only for phone numbers marked as "mobile".  
    baseRecipientAdapter.setShowMobileOnly(false);
    
    phoneRetv.setAdapter(baseRecipientAdapter);
    ```
  </Step>
</Steps>

<Tip>
  Set `setShowMobileOnly(true)` if you want to filter only mobile phone numbers and exclude landlines.
</Tip>

## Retrieving selected chips

Once users have selected contacts, you can retrieve them using `getSortedRecipients()`:

```java
DrawableRecipientChip[] chips = phoneRetv.getSortedRecipients();

for (DrawableRecipientChip chip : chips) {
    String displayName = chip.getEntry().getDisplayName();
    String destination = chip.getEntry().getDestination();
    
    Log.d("Chip", displayName + ": " + destination);
}
```

## Complete example

Here's a complete Activity implementation with permission handling:

```java
public class MainActivity extends AppCompatActivity {

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);

        // Request READ_CONTACTS permission if not granted
        if (ContextCompat.checkSelfPermission(this, Manifest.permission.READ_CONTACTS)
                != PackageManager.PERMISSION_GRANTED) {
            ActivityCompat.requestPermissions(this,
                    new String[]{Manifest.permission.READ_CONTACTS}, 0);
        }

        // Set up phone number autocomplete
        final RecipientEditTextView phoneRetv =
                (RecipientEditTextView) findViewById(R.id.phone_retv);
        phoneRetv.setTokenizer(new MultiAutoCompleteTextView.CommaTokenizer());
        BaseRecipientAdapter adapter = new BaseRecipientAdapter(
            BaseRecipientAdapter.QUERY_TYPE_PHONE, 
            this
        );
        adapter.setShowMobileOnly(true);
        phoneRetv.setAdapter(adapter);
        phoneRetv.dismissDropDownOnItemSelected(true);
    }
}
```

## Additional configuration

The library provides several optional configuration methods:

```java
// Automatically dismiss dropdown when user selects an item
phoneRetv.dismissDropDownOnItemSelected(true);

// Show all contacts in dropdown (useful for button click)
phoneRetv.showAllContacts();

// Filter for mobile numbers only
baseRecipientAdapter.setShowMobileOnly(true);
```
